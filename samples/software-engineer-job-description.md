Software Engineer (Full-Stack) – Meghna Digital

About Meghna Digital
Meghna Digital builds online ordering and delivery software for restaurants and grocery shops in Bangladesh. More than 1,500 businesses use our platform to take orders, manage riders and get paid through bKash, Nagad and cards. We are a team of 60, with 18 engineers, and we release to production every day.

The role
We are hiring a Software Engineer to join our Orders team. You will build features end to end, from the database and REST APIs to the screens our merchants use every day. You will work closely with a product manager, a designer and four other engineers. This is a hybrid role based in Dhaka, Bangladesh: 3 days a week in our Banani office, 2 days from home.

What you'll do
- Build and maintain REST APIs in Node.js and TypeScript
- Build merchant-facing screens in React and TypeScript
- Design database tables and write efficient queries in PostgreSQL
- Write unit and integration tests, and keep our CI pipeline green
- Take part in code reviews and share what you learn with the team
- Investigate and fix production issues, using our logs and monitoring
- Help improve performance and reliability as order volume grows

Must-have requirements
- 3+ years of professional software development
- Strong TypeScript or JavaScript
- Building REST APIs with Node.js (Express, NestJS or similar)
- Building user interfaces with React
- SQL databases, preferably PostgreSQL
- Writing automated tests (Jest, Vitest or similar)
- Working with Git and pull-request code reviews

Nice to have
- Docker and a cloud platform (AWS preferred)
- Redis, queues or background jobs
- CI/CD pipelines (GitHub Actions or similar)
- Payment gateway integrations (bKash, Nagad, SSLCommerz)
- Experience with high-traffic or real-time systems

What we offer
- Salary: BDT 150,000 – 220,000 per month, plus a yearly performance bonus
- Health insurance for you and your family
- Learning budget of BDT 40,000 per year
- New laptop and home-office allowance
- 20 days of paid leave, plus public holidays

How to apply
Send your CV and a short note about a project you're proud of to careers@meghnadigital.example.com.
